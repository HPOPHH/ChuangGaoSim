About

关于本工具

本工具用于自主生成 json 数据，并使用官方算法签名后提交，实现运动数据的自动化记录

实现介绍

1. 分析创高体育客户端的网络协议，梳理出请求签名的生成方式，确认核心签名逻辑位于本地算法库中；

2. 整理该算法库的调用方式，使其可以在自行开发的应用中同样生成有效签名；

3. 通过协议梳理确定各接口的参数格式，并按相同格式构造请求。

4. 新增图片上传功能，完善数据提交流程。
